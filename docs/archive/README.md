# Documentation archive

This directory preserves implementation history and regression evidence. It is not part
of routine task context and must not be read merely to understand the current product.

Use the active root documents and `docs/BACKLOG.md`, `docs/TESTING.md`, and
`docs/DATA-FORMATS.md` first. Read archived material only when the owner requests it or a
specific regression/decision investigation needs historical evidence. If history conflicts
with an active canonical document or verified current behavior, the active source wins.

`V1-IMPLEMENTATION-HISTORY.md` consolidates the completed Amazon-context and frontend-
migration plans that previously lived in the active `docs/` directory.
